#### 🧾 초간편 수입, 지출 기록  
- 텍스트로 말하듯 자연스럽게 ex("점심 김치찌개 8000원")
- 영수증 사진 한 장으로 자동 인식
- AI가 금액, 카테고리, 감정까지 자동 분석

#### 🍀 AI 캐릭터 '토닥이'와의 대화 
- 공감형, 목표지향형
- 시간대별 나에게 딱 맞는 인사와 격려 메시지

#### 📅 수입, 지출 캘린더  
- 월간 내역을 한눈에 파악

#### 🧐 인사이트 리포트
- 월간/주간 지출 요약 및 예산 대비 현황 파악
- 주간 감정 분포 차트
